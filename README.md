# Multi-Language Text Translator (Python CLI)

#Overview
This is a command-line based language translator built using Python. It allows users to translate text into multiple languages such as Hindi, Spanish, French, German, and more using a simple and interactive interface.-

# Features
-  Supports multiple languages
-  Simple and user-friendly CLI interface
-  Dynamic language selection
-  Input validation and exception handling
-  Fast and lightweight execution
